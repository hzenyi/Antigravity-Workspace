## 一、電路設計核心觀念 【教材 p. 0-2】

> 📖 **課本出處**：第零章 p. 0-2〈瞧！電路設計〉、〈0-1 電路設計開始〉

電路設計是將抽象的電子意念具體實現為可動作硬體商品的過程：

```text
[電子意念/功能需求]
       │
       ▼
[繪製電路圖 (Schematic)] ──> 交代零件型號、接腳對應與連線關係
       │
       ▼ (電路模擬 Verification)
[轉換為電路板 (PCB Layout)] ──> 實體零件封裝尺寸、板材輪廓、走線排佈
       │
       ▼
[實體製作 (蝕刻/雕刻/洗板)] ──> 焊接組裝零件 ➔ 完成硬體成品（向麵包板說再見）
```

- **專案 (Project) 的角色**：Altium Designer 必須透過「專案檔 (`.PrjPCB`)」將電路圖檔 (`.SchDoc`) 與電路板檔 (`.PcbDoc`) 連結起來，電路板才知道向哪個電路圖要零件資料與連線網路。

## 二、實作流程總覽圖

```text
┌──────────────────────────────────────────────────────────┐
│                   Altium Designer 標準流程                │
└──────────────────────────────────────────────────────────┘
  [1. 新建專案] ➔ 加入電路圖檔 (.SchDoc) 與 PCB 檔 (.PcbDoc) ➔ 存檔 (p. 0-3~0-4)
       │
  [2. 繪製電路圖] ➔ 從零件庫放置元件 (電晶體、電阻、電容、LED、電池) (p. 0-4~0-10)
       │
  [3. 零件編序] ➔ 工具 / 零件序號自動編序 (消除紅色波浪底線 ECO) (p. 0-10~0-12)
       │
  [4. 導入 PCB] ➔ 設計 / Import Changes ➔ 載入元件到 Room (p. 0-12~0-13)
       │
  [5. 零件佈局] ➔ 拖曳至黑色編輯區排版 ➔ 旋轉元件與調整文字 ➔ 刪除 Room (p. 0-13~0-14)
       │
  [6. 定義板形] ➔ Keep-Out Layer 繪製封閉框 ➔ 設計 / 板形設計 / 定義板形 (p. 0-15)
       │
  [7. 自動佈線] ➔ 設定規則 (單層板 Bottom Layer) ➔ Auto Route All 佈線完成 (p. 0-15~0-17)
```

## 步驟 1：建立專案與檔案管理 【教材 p. 0-3 ~ 0-4】

### 1.1 新增專案與檔案 【教材 p. 0-3，對應圖 1】
1. 啟動 **Altium Designer**。
2. 執行選單：`檔案 (File)` ➔ `新增 (New)` ➔ `專案 (Project)` ➔ `電路板專案 (PCB Project)`。
   - 左側 `Projects` 面板將出現暫存專案 `PCB_Project1.PrjPCB`。
3. 在 `Projects` 面板的 `PCB_Project1.PrjPCB` 上按**滑鼠右鍵**：
   - 點選 `新增檔案到專案 (Add New to Project)` ➔ `Schematic`，產生電路圖檔（白底編輯區 `Sheet1.SchDoc`）。
4. 再次於專案上按**滑鼠右鍵**：
   - 點選 `新增檔案到專案 (Add New to Project)` ➔ `PCB`，產生電路板檔（黑底編輯區 `PCB1.PcbDoc`）。

### 1.2 專案與檔案另存新檔 【教材 p. 0-4】
> [!IMPORTANT]
> 此時專案與檔案名稱右側多出一個星號 `*`，代表這只是記憶體中的暫存項目，尚未寫入硬碟！
1. 在專案名稱 `PCB_Project1.PrjPCB` 上按**滑鼠右鍵** ➔ 點選 `另存專案... (Save Project As...)`。
2. 先在硬碟建立專屬資料夾（課本範例為：`D:\Examples\CH0`）。
3. 依序在存檔對話盒中指定路徑與檔名：
   - **電路板檔案**：保持為原來的 `PCB1.PcbDoc` ➔ 按「存檔」。
   - **電路圖檔案**：指定名稱為 `Alter.SchDoc` ➔ 按「存檔」。
   - **專案檔案**：指定名稱為 `CH0.PrjPCB` ➔ 按「存檔」。
4. 完成存檔後，專案名稱旁的 `*` 消失。隨時養成按 **`Ctrl + S`** 存檔的好習慣。

## 步驟 2：繪製電路圖 (Schematic Capture) 【教材 p. 0-4 ~ 0-10】

> 📖 **課本出處**：〈0-2 繪製電路圖〉（p. 0-4）  
> 本電路為雙晶體非穩態交互閃爍電路（會交替閃爍的 LED 警示燈）。

### 2.1 取用零件 (Libraries 面板) 【教材 p. 0-4 ~ 0-8】
1. 滑鼠指向編輯區右側的 **`零件庫 (Libraries)`** 標籤（浮出零件庫面板）。
2. 上方確認選取整合零件庫：`Miscellaneous Devices.IntLib`。

#### 放置電晶體 (2N3904) 【教材 p. 0-4 ~ 0-5，對應圖 2】
1. 在搜尋名稱欄位輸入 `2N3904`。
2. 面板右上角按鈕變為 **`Place 2N3904`**，按一下此鈕。
3. 游標移至白底編輯區，出現浮動電晶體符號。
4. 移動至適當位置按**滑鼠左鍵**放置第一個電晶體。
5. 按鍵盤 **`X` 鍵**（將游標上的電晶體**左右水平翻轉**，p. 0-5 步驟 5）。
6. 移動至右側位置按**滑鼠左鍵**放置第二個電晶體。
7. 按**滑鼠右鍵**結束電晶體放置。

> [!NOTE]
> **為什麼有紅色波浪線？【教材 p. 0-6，對應圖 3】**  
> 此時電晶體右邊各有一條紅色波浪線（課本俗稱「毛毛蟲」），是因為序號皆為未指定的 `Q?` 重複衝突。此階段先不理它，稍後執行自動編序即可一次消除。

#### 放置電阻器 (Res1) 【教材 p. 0-6 ~ 0-7，對應圖 4、圖 5】
1. 零件庫搜尋名稱輸入 `Res1` ➔ 點擊 **`Place Res1`**。
2. 游標浮動電阻時，按一下鍵盤 **`Tab` 鍵**開啟元件屬性對話盒（p. 0-6 圖 4）：
   - 在 **`Comment`** 欄位輸入電阻值 `1K`。
   - 取消勾選 `Value` 左邊的核取方塊（隱藏冗餘標記）。
   - 按 `OK` 關閉對話盒。
3. 按鍵盤 **`空白鍵 (Space)`** 旋轉 90 度（變垂直）。
4. 在兩側 LED 上方各放置 1 顆 `1K` 電阻。
5. 重複按 `Tab` 鍵，將 `Comment` 改為 `47K`，放置 2 顆 `47K` 電阻於中間（p. 0-7 圖 5）。
6. 按滑鼠右鍵結束電阻放置。

#### 放置電容、LED 與電池 【教材 p. 0-7 ~ 0-8，對應圖 6】
- **電容器 (Cap)**：取用 `Cap`，按 `Tab` 設定電容值，左邊放置 `0.1uF`，右邊放置 `0.22uF`。
- **發光二極體 (LED0)**：取用 `LED0`，放置 2 顆。
- **電池 (Battery)**：取用 `Battery`，放置於最左側。
- 完成取用如課本 p. 0-8 圖 6 所示（共 11 個零件）。

---

### 2.2 連接線路 (Wiring) 【教材 p. 0-8 ~ 0-10，對應圖 7 ~ 10】

1. 按快捷鍵 **`P` ➔ `W`** 進入連接線路狀態（Place Wire），游標變為十字準星（p. 0-8）。
2. 將游標指向起點接腳端點（出現紅色十字連接提示），按**滑鼠左鍵**開始拉線。
3. 移至目標接腳端點，按**滑鼠左鍵**完成連接（p. 0-8 圖 7）。
4. **線路轉彎與繪製斜線技巧 【教材 p. 0-9，對應圖 8、圖 9】**：
   - 預設為直角模式；在未定狀態下按 **`Shift + 空白鍵`** 可切換轉角模式。
   - **若原本為直角模式，按 `Shift + 空白鍵` 兩下即可切換為斜線模式！**
   - 按滑鼠左鍵固定前一段斜線，再移至另一端點按滑鼠左鍵完成交叉連線。
   - 單獨按 **`空白鍵`** 可改變轉角折彎方向。
5. 依照課本 **p. 0-10 圖 10** 完成全電路接線。

## 步驟 3：零件自動編序 (解決紅色毛毛蟲) 【教材 p. 0-10 ~ 0-12】

> 📖 **課本出處**：〈零件自動編序〉（p. 0-10 ~ 0-12，對應圖 11 ~ 14）

在圖 10 裡元件爬滿紅色毛毛蟲，透過自動編序（Annotation）進行除蟲：

1. 執行上方選單：`工具 (Tools)` ➔ `零件序號自動編序 (Annotate Schematics...)`（p. 0-10 圖 11）。
2. 在對話盒左下方點擊 **`更新序號 (Update Changes List)`**：
   - 系統會在建議值/序號欄位自動安排序號（如 R1~R4, Q1~Q2, C1~C2, D1~D2, BT1）。
3. 點擊右下方 **`接受變更(建立ECO) (Accept Changes / Create ECO)`**。
4. 跳出確認訊息對話盒（p. 0-11 圖 12），顯示「11 change(s) made」，按 `OK`。
5. 開啟「工程變更設計 (ECO)」視窗（p. 0-11 圖 13），點擊左下方 **`執行變更動作 (Execute Changes)`**：
   - 檢查右側狀態欄位均順利完成打勾。
6. 點擊 `關閉 (Close)` 退回前一個對話盒，再按 `關閉` 返回編輯區。
7. **編序完成檢驗 【教材 p. 0-12，對應圖 14】**：
   - 所有零件序號已固定且紅色毛毛蟲全數消失。
   - 按 **`Ctrl + S`** 存檔。
   - 按 **`Ctrl + PgDn`** 放大顯示全圖；若發現多餘的不小心點出的圖件，選取後按 `Delete` 刪除。

## 步驟 4：轉移至 PCB 與零件佈置 (Placement) 【教材 p. 0-12 ~ 0-14】

> 📖 **課本出處**：〈0-3 設計電路板〉、〈導入電路圖資料〉、〈零件佈置〉（p. 0-12 ~ 0-14）

### 4.1 導入電路圖資料到 PCB 【教材 p. 0-12 ~ 0-13，對應圖 15、圖 16】
1. 點擊標籤切換到黑底的電路板編輯區 **`PCB1.PcbDoc`**。
2. 先確認已存檔（`Ctrl + S`）。
3. 執行選單：`設計 (Design)` ➔ **`Import Changes From CH0.PrjPcb`**。
4. 開啟工程變更設計對話盒（p. 0-13 圖 15），點擊 **`執行變更動作 (Execute Changes)`**。
5. 變更完成後按 `關閉 (Close)`。
6. 按 **`PgUp`** 縮小編輯區顯示比例，即可在右側粉紅色方框看到載入的零件與網路飛線（p. 0-13 圖 16，此粉紅區域稱為 **CH0 零件擺置區間 / Room**）。

### 4.2 零件佈局與排文字 【教材 p. 0-13 ~ 0-14，對應圖 17 ~ 19】
1. **拖曳零件**：
   - 按住滑鼠左鍵拖曳零件移入黑色編輯區，拖曳過程中按一下 **`空白鍵`** 旋轉零件。
   - 依電路圖相對位置完成初步排列（p. 0-14 圖 17）。
2. **刪除零件擺置區間 (Room) 【教材 p. 0-14，對應圖 18】**：
   - 零件全數移出後，滑鼠點選紅色的 CH0 擺置區間，按 **`Delete`** 鍵將其刪除。
3. **統一文字方向 【教材 p. 0-14，對應圖 19】**：
   - 零件序號文字（如 R1、Q1 等）方向不一時，按住文字拖曳並按 **`空白鍵`** 改變文字朝向，全部轉為同一水平方向。
4. 按 **`Ctrl + S`** 存檔。

## 步驟 5：定義板形 (Keep-Out Layer 切板) 【教材 p. 0-15】

> 📖 **課本出處**：〈板形設計〉（p. 0-15，對應圖 20）

1. **切換至禁置板層**：點擊工作區底部的 **`Keep-Out Layer`** 板層標籤。
2. **繪製外框線**：
   - 按快捷鍵 **`P` ➔ `L`** 進入畫線狀態。
   - 點選板框起點，拉出線條。可按 **`Shift + 空白鍵`** 切換為直角轉角模式。
   - 依序圍繞零件四周拉出矩形，回到原本起點頭尾相接（無破洞）後連按兩下滑鼠左鍵，再按兩下滑鼠右鍵結束。
3. **全選板框線**：
   - 按住鍵盤 **`Shift` 鍵**，用滑鼠一一選取 4 段外框線（如 p. 0-15 圖 20 左圖）。
4. **重新定義板形 (切板)**：
   - 執行選單：`設計 (Design)` ➔ `板形設計 (Board Shape)` ➔ **`根據選取物件定義板形 (Define from selected objects)`**。
   - 黑色電路板即依選取線段完成裁剪（如 p. 0-15 圖 20 右圖）。點擊空白處取消選取。

## 步驟 6：設定設計規則與自動佈線 (Auto-Routing) 【教材 p. 0-15 ~ 0-17】

> 📖 **課本出處**：〈編輯設計規則〉、〈自動佈線〉（p. 0-15 ~ 0-17，對應圖 21 ~ 23）

### 6.1 設定單層板設計規則 【教材 p. 0-15 ~ 0-16，對應圖 21】
1. 執行選單：`設計 (Design)` ➔ `設計規則 (Rules...)`。
2. 切換到樹狀目錄：`Routing` ➔ **`Routing Layers`**（p. 0-16 圖 21）。
3. **取消勾選 `Top Layer`**（不容許在頂層走線），**僅保留 `Bottom Layer`**（限制只能在底層走藍色銅箔線）。
4. 點擊 `確認 (OK)` 關閉對話盒。

### 6.2 執行自動佈線 【教材 p. 0-16 ~ 0-17，對應圖 22、圖 23】
1. 執行選單：`自動佈線 (Auto Route)` ➔ `整塊電路板 (All...)`。
2. 出現自動佈線設定對話盒（p. 0-17 圖 22），直接點擊 **`Route All`** 按鈕。
3. 程式即進行全面自動佈線（約 1 秒鐘即可完成）。
4. 關閉右上角遮擋視線的 Messages 面板。
5. 檢視成果：全板呈現藍色單層銅箔走線（p. 0-17 圖 23）。
6. 按 **`Ctrl + S`** 完成存檔！

### 🛠️ 初學者常見問題與除錯錦囊 (Troubleshooting)

1. **Q：電路圖上為什麼有紅色波浪底線（毛毛蟲）？【教材 p. 0-6, 0-10】**
   - **原因**：元件序號未指定（如 `Q?`）或重複。
   - **解法**：執行 `工具` ➔ `零件序號自動編序` ➔ 建立 ECO 執行變更即可消除。
2. **Q：畫導線時拉不出斜線？【教材 p. 0-9】**
   - **解法**：在拉線未定狀態下，連按兩次 **`Shift + 空白鍵`** 切換為斜線模式。
3. **Q：切板 (Define Board Shape) 失敗？【教材 p. 0-15】**
   - **原因**：板框未閉合，或未按住 `Shift` 將 4 段外框線全部選取。
4. **Q：自動佈線跑出紅色走線？【教材 p. 0-16】**
   - **原因**：紅色為頂層走線。若為單面板，請至 `Design ➔ Rules ➔ Routing Layers` 取消勾選 Top Layer。
