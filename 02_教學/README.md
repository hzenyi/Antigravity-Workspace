# 教學工作智慧治理與任務基座 (A02_教學工作)

本專案工作區依據**課程與專業屬性 (Subject/Domain)** 進行模組化分群管理，並構建為 **Pedagogical Harness Engines（教學智慧治理與任務基座）**，支援全校各專業學科之教案設計、教材產生、出作業、收作業、改作業與學習診斷。

## 智慧治理基座 (Harness Engines)

本專案由全域「高工資訊科老師」主持，調用電子/程式領域專家 (SMEs)，透過外骨骼治具驅動四大專業引擎：

1. **學科與任務路由 (Task Router)**：自動識別科目領域（電路繪圖/網路管理/資料庫等）並派工至對應教學引擎。
2. **四大教學驅動引擎 (Engines)**：
   - 🚀 **E1 教案規劃引擎**：108 課綱核心素養與學習表現單元教案。
   - 🚀 **E2 教材講義引擎**：多模態素材萃取（PDF/照片/網址），強制標註課本原頁碼與圖號。
   - 🚀 **E3 評量設計引擎**：情境導向 PBL 作業說明書與四級客觀 Rubric 評分量規。
   - 🚀 **E4 批改診斷引擎**：三段式回饋（肯定亮點 ➔ 診斷盲點 ➔ 階梯式引導，無直接給解答代碼）。
3. **不可逾越之教學防護紅線 (Redline Guardrails)**：
   - 學生個資全面代號化保護（座號/代號）。
   - 做中學引導紅線（嚴禁直接給完整解答代碼，保留除錯思考）。
   - 教材來源真實性（精準標註課本頁碼圖號，無幻覺）。
4. **教學品質審核閘門 (Review Gates)**：產出前強制執行 5 大校驗與自修復回路（最多 3 次）。
