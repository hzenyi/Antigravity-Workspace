# 教學輔助工具與自動化腳本 (Tools & Scripts)

本目錄用於存放提升教學行政與作業管理效率之自動化工具與腳本。

## 規劃工具範例
- **`check_submissions.py`**：自動比對繳交清冊與實際收到檔案，產出未繳交學生名單。
- **`generate_feedback_docx.py`**：將 Markdown 批改回饋批次轉為 Word 或 PDF 檔方便發送。
- **`score_summary.py`**：計算作業各題得分率、平均值、標準差與級距分佈圖表。

> 若需要任何自動化功能，隨時告訴 AI，我們可在此建立對應的 Python 工具腳本！
