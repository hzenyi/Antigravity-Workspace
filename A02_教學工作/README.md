# 教學工作專案工作區 (A02_教學工作)

本專案工作區依據**課程與專業屬性 (Subject/Domain)** 進行模組化分群管理，支援全校各專業學科之教案設計、教材產生、出作業、收作業、改作業與評量測驗。

---

## 智慧自動分類機制 (AI 自動歸檔)

當您在對話中提供新的教學素材或提出需求時，AI 會自動：
1. **分析課程屬性**：判斷是屬於「電路繪圖」、「網路管理」、「資料庫」或其他新科目（如「程式設計」、「微處理機」等）。
2. **自動建立/對應目錄**：若為全新科目，會主動建立該學科專屬資料夾；若已存在，則直接歸納到該科目下的對應子目錄（`教材講義/`、`教案規劃/`、`作業與評量/`、`參考資料/`）。
3. **精準對照課本頁碼**：對於講義或教案，自動標註書本原頁碼與圖號，方便學生紙本對照。
