# 01_公文處理作業指南

本目錄提供學校行政公文（簽呈、函、開會通知單、書函、公告）之撰寫原則、格式規定與校對清單。

---

## 一、公文分項標號規範

依行政院文書處理手冊規定，公文分項標號層級如下，不得跳級或混用：

- 第一層：`一、`、`二、`、`三、`
- 第二層：`（一）`、`（二）`、`（三）`（注意全形括號，後面不加頓號）
- 第三層：`1、`、`2、`、`3、`
- 第四層：`（1）`、`（2）`、`（3）`（注意全形括號，後面不加頓號）
- 第五層：`(i)`、`(ii)`、`(iii)`

---

## 二、簽呈與公函架構差異

### 1. 簽呈（內部文）
- **性質**：機關內部同仁向長官請示、陳報之行政文書。
- **標準三段式**：
  - **主旨**：扼要說明簽請之核心事件與目的（一段完成，不分項）。
  - **說明**：交代背景、緣由、法規依據、現況分析、經費來源等細節。
  - **擬辦**：提出具體處置建議或執行方案，供長官核定批示。

### 2. 函（對外文）
- **性質**：本校對上級機關（如教育局/教育部）、平行機關（其他學校、民間機構）或下屬單位行文之公文。
- **標準三段式**：
  - **主旨**：表明行文之目的、主體要求（一段完成，不分項）。
  - **說明**：敘明事實、法規來由、檢附附件名稱及份數。
  - **辦法/擬辦**：對受文者提出具體配合要求、辦理期限或作業方式（平行或下行文用「辦法」；上行文則將請示事項併入說明段或用「請 核示」）。

## 三、常用期望語與公文禮儀（挪抬準則）

1. **挪抬規範**：遇「長官稱謂」、「受文者學校/機關抬頭」時，於文字前空一格表示尊重。
   - 例：`陳 鈞長核示`、`請 查照`、`敬請 惠允同意`、`貴校`。
2. **期望語對照表**：
   - **上行文（向教育局、教育部請示/報核）**：`請 鑒核`、`請 察核`、`請 核示`。
   - **平行文（與他校、同級機關協商/告知）**：`請 查照`、`請 惠予同意`、`請 惠允協助`。
   - **下行文（對校內各單位、學生、受規範對象）**：`請 照辦`、`請 查照辦理`。

## 四、公文擬稿問答引導與協作工作流程

當需要起草或潤飾公文時，AI 助理將嚴格遵循以下互動流程：

1. **接收歷史範本與附件資料**：
   - 使用者可提供過去的公文範本，AI 將優先參酌其既有風格、用字習慣與結構。
   - 使用者可提供相關法規、來文、會議紀錄或企劃書作為附件，AI 將深入研讀並提取重要公文字號、事實與日期。
2. **問答釐清需求 (Q&A Clarification)**：
   - 若資訊尚有模糊或缺漏，AI 會主動透過**結構化問答**向使用者確認：
     - 行文對象與公文類型（簽呈 / 上行函 / 平行函 / 開會通知單）
     - 發文目的與核心主旨
     - 來文依據或法規條款
     - 重要期程、地點、受惠對象與經費項目
     - 檢附之附件清單
3. **付諸實現與出稿**：
   - 要件對齊後，即刻產出符合規範之公文全文，並提示公文核章與送發之注意事項。
