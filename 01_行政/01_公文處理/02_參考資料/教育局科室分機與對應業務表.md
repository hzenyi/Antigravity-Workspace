# 教育局常用科室與對應業務參照表

在簽呈之說明段或公文聯繫時，應指明對應主辦科室，便於文向流通與承辦窗口對接。

| 科室名稱 | 主要執掌業務 | 常見行文與對接事由 |
| :--- | :--- | :--- |
| **中等教育科 (中教科)** | 普通型高中、綜合高中課務、學籍、行政組織 | 高中招生、課綱審查、前導學校計畫、教學設備補助 |
| **技職教育科 (技職科)** | 技術型高中（高職）、實習處業務、產學合作 | 專題競賽、技藝競賽、技能檢定、實習材料費、技優甄審 |
| **學事科 / 國教科** | 國民中學、國民小學課務、學區劃分 | 完全中學國中部業務、學區編班、免試入學 |
| **學務校安室 (體健科/校安室)** | 學生事務、生活輔導、校園安全防護、性平防制 | 校安通報、霸凌防制、學生獎懲申訴、防災演練 |
| **特殊教育科 (特教科)** | 身心障礙學生、資賦優異學生鑑定與輔導 | 個別化教育計畫 (IEP)、特教評鑑、巡迴輔導資源 |
| **資訊教育科 / 數資中心** | 智慧校園、數位學習、校園網路、AI 教育推動 | 生生用平板計畫、智慧學習教室建置、資訊設備採購 |
| **人事室 (教育局端)** | 校長與公立教師甄選、主任甄選、介聘、考績核定 | 教師敘薪、超額教師介聘、成績考核覆核 |
| **政風室 (教育局端)** | 校園廉政、採購監辦、陳情與檢舉調查 | 採購履約爭議、匿名陳情案查處回覆 |
