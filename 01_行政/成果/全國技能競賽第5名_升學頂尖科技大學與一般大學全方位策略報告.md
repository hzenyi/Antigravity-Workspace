## 壹、 核心法規觀念釐清：是「保送」還是「甄審」？

在與會長溝通時，首先務必清楚說明教育部的法定分水嶺，避免產生「全國得獎＝直接保送」的預期落差，同時讓會長明白「甄審」反而對公子更有利：

| 評比維度 | 技優「保送」入學 | 技優「甄審」入學（🎯 公子主力戰場） |
| :--- | :--- | :--- |
| **法定門檻** | 限全國技能競賽 **前 3 名（金、銀、銅牌）** | 全國技能競賽 **前 5 名及優勝皆符合資格** |
| **第 5 名資格判定** | ❌ **不符合保送資格** |  **完全符合資格，且享有最高檔次加分** |
| **成績加分機制** | 無須加分，直接依志願分發 | **甄審實得總分增加 25%**（青年組第 4、5 名標準） |
| **統一入學測驗（統測）** | **完全不採計** | **完全不採計**（不被學科筆試拖累） |
| **招生名額與校系** | 名額極少（每系通常僅 1~2 名） | **招生名額多，頂尖國立名校所有熱門科系全面開放** |
| **志願填報上限** | 依簡章分發 | 至多選填 **5 個校系科（組）、學程** |

> 📌 **給會長的安心解讀**：  
> 雖然法規限定前 3 名才能保送，但保送往往只能分發到特定極少數名額；而「技優甄審」名額多、校系廣，手握 **25% 高額加分** 的選手在甄審戰場上幾乎具備絕對統治力，錄取臺科大、北科大等第一志願的機率極高！

## 貳、 技優甄審「分數計算機制」與「專利加分法規」深度剖析

### 一、 技優甄審分數計算公式
技優甄審的最終錄取依據為「甄審總成績」，其法定公式為：

$$\mathbf{甄審總成績} = \mathbf{指定項目甄審實得總分} \times (1 + \mathbf{優待加分比例})$$

或寫作：
$$\mathbf{甄審總成績} = \mathbf{甄審實得總分} + (\mathbf{甄審實得總分} \times 25\%)$$

1. **指定項目甄審實得總分（滿分 100 分）**：各大學系所自訂的評分項目（如：學習歷程書審 50% ＋ 面試 50%）。
2. **優待加分（增加 25%）**：直接將各校實得總分乘上 $1.25$。最終總成績計算至小數點後第 2 位（第 3 位四捨五入）。
3. **分數破百是常態且合法**：加分後超過 100 分（如 110～115 分）完全被系統採計，不會被強制截斷或扣除。

---

### 二、 重要法規釐清：專利在技優甄審能重複加分嗎？
- **法定加分標準**：中華民國發明專利加分 15%、新型專利加分 8%。
- **教育部的鐵律——「擇優採計一項，不得累計」**：
  - 若考生同時持有競賽獎狀與專利證書，系統規定**只能挑選加分幅度最高的一項**。
  - 因此系統會自動採計**「全國技能競賽第 5 名（加分 25%）」**，而**不會**變成 $25\% + 15\% = 40\%$。
- **專利的真正「核彈級價值」在於乘數效應**：
  - 既然加分乘數固定是最高級別的 $\mathbf{1.25}$，專利的最大威力就是**把被乘數（實得總分）推上 95～98 分的頂峰**！

### 三、 實戰試算：全國第 5 名 ＋ 專利的碾壓級優勢

以申請「國立臺北科技大學 機械工程系」為例（審查資料 50% ＋ 面試 50%）：

```
【令公子的成績換算（全國第 5 名 + 專利發明人）】
  • 書面審查（全國獎狀 + 專利證書）：獲得 94 分 (94 × 50% = 47.0 分)
  • 現場面試（攜帶實體作品 + 專利解說）：獲得 92 分 (92 × 50% = 46.0 分)
  ➔ 甄審實得總分 = 47.0 + 46.0 = 93.0 分
  ➔ 甄審總成績 = 93.0 × (1 + 0.25) = 93.0 × 1.25 = 116.25 分 (極頂級高分！)

【對照組：僅持乙級技術士證的一般頂尖考生（加分 15%）】
  • 即使表現極為優異，書審 90 分、面試 90 分，拿到高達 90 分的實得總分：
  ➔ 甄審總成績 = 90.0 × (1 + 0.15) = 90.0 × 1.15 = 103.50 分
```

> 🏆 **結論**：令公子以 **116.25 分 大幅領先 103.50 分 多達 12.75 分**！在競爭激烈的頂大甄試中，0.5 分就能決定勝負，12 分以上的差距基本上就是**穩拿正取第一名（狀元）**！

## 肆、 備審資料（學習歷程檔案）金獎級撰寫攻略

要讓教授在書面審查打出 95 分以上的頂級分數，備審資料必須精準掌握以下四大主軸，將素材轉化為打動教授的專業語言：

### 一、 選手心得與反思（展示 RCA 根本原因分析與排錯思維）
- **教授的痛點**：最討厭只報喜不報憂的流水帳。在工程領域，教授看重的是**「面對失敗時的工程診斷能力」**。
- **撰寫技巧**：
  1. 挑選競賽集訓中「最慘烈的一次失敗」或「全國賽現場的突發盲測題」。
  2. 依循工程邏輯條理記錄：
     - **異常現象（Symptom）**：機構卡死、伺服馬達抖動、或公差超標 0.05mm。
     - **原因排查（Root Cause Analysis）**：如何利用量具、示波器或回溯代碼，層層推導出問題根源。
     - **處置對策（Countermeasure）**：在倒數時間壓力下，如何冷靜調整架構或加工參數修復成功。
  3. **結語反思**：這場經歷如何鍛鍊出「臨危不亂的沉著心態與嚴謹的工程邏輯」。

### 二、 設計與參賽的心路歷程（黃金故事線：從競賽痛點到專利誕生）

## 伍、 現場面試「三大殺手級神器」與隱藏加碼紅利攻略

### 一、 面試攜帶「三大殺手級神器」（強烈建議！）

在面試現場，如何徹底壓制其他考生？教務團隊建議採用以下實戰配置：

1. **神器一：攜帶「實體精華作品 / 專利原型機構」進場（奪取提問主導權）**
   - **戰術優勢**：空手進去的學生只能被動回答教授突發的理論考題；但當令公子把精美、安全的金屬/機構實體作品往教授面前一放，整場 8～10 分鐘的面試，**教授所有提問 100% 都會圍繞著桌上的作品展開**！
   - **實務守則**：體積不宜過大（手提工具箱可容納為準），務必擦拭乾淨，不得有尖銳毛邊或漏電隱患；若屬資訊/控制類，請自備充飽電的 iPad 離線展示動態操作影片。
2. **神器二：呈遞「教授專用 A4 雙面彩色列印精華三折頁（共 5 份）」**
   - 面試委員通常有 3～5 位，桌上只有一件作品，外側的教授看不清楚。
   - **解法**：進場向教授鞠躬問候後，雙手呈遞每位教授一份精美三折頁，內含：**個人照片、全國第 5 名獎盃、專利名稱與案號、機構 3D 渲染圖、技術特點條列**。這會讓教授立刻感受到無與倫比的專業度與誠意！
3. **神器三：攜帶「經濟部專利證書」正本（附燙金官方徽飾）**
   - 裝入硬質透明資料夾。在解說作品時禮貌說明：*「這項作品的核心創新技術，已通過經濟部審查取得專利證書，專利證號為：第 XXXXX 號，現場備有證書正本供教授參閱……」*。這句話一出，現場層次直接躍升為研究生論文發表會！

### 二、 選手隱藏權益與加碼紅利總盤點

除了升學加分，這項全國賽成就尚有三大隱藏實質權益，務必提醒會長：

1. **乙級/丙級技術士證「免試術科測試」優惠（極大實惠！）**
   - **法規依據**：《技術士技能檢定及發證辦法》第 11 條。
   - **權益內容**：自全國賽及格日起 **3 年內**，報考同職類之技術士技能檢定，**得直接申請免除術科測試**！
   - **實務效益**：令公子只要報考並通過單純的「學科選擇題筆試（60分及格）」，即可**直接獲頒「乙級技術士證」**！
2. **合法保留「下一屆再戰全國前三、直取技優保送」的資格**
   - **關鍵賽制規定**：勞動部競賽規章明確明訂——曾獲全國前 3 名者「不得」再參賽同組同職類；但**「第 4、5 名完全不受限制」**！
   - **升學大跳級機會**：只要年齡符合規定（青年組通常在 21～22 歲內），公子高三仍具備再次代表學校挑戰全國技能競賽的資格。若下一屆奪下前 3 名（金、銀、銅），即可**直接解鎖教育部「技優保送」（免筆試直接分發臺科大、北科大第一志願）**，並取得進軍國際技能競賽（WorldSkills）國手選拔賽的資格！
3. **縣市政府優秀選手獎勵金申請**
   - 設籍或就讀該縣市之勞工局、職能發展學院或教育局，通常針對全國技能競賽獲獎者訂有選手培育獎學金，務必於獲獎日起 **3 個月內** 檢附公文獎狀提出申請。
