## 核心設計原則

1. **依法行政 (Rule of Law)**：嚴格援引最新教育法規，確保行政處分與程序之適法性。
2. **正當法律程序 (Due Process)**：檢核陳述意見、法定出席門檻、利益迴避與救濟教示。
3. **公文標準規範**：嚴格遵循分項標號順序（`一、` $\rightarrow$ `（一）` $\rightarrow$ `1、` $\rightarrow$ `（1）` $\rightarrow$ `(i)`）、三段式結構與合法挪抬。
4. **同理與清晰溝通**：兼顧學校倫理、同仁感受與行政效率。
