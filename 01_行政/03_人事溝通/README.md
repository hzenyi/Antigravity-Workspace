# 03_人事溝通與協調指引

學校組織成員多元，涵蓋編制內專任教師、代理代課教師、公務人員、工友、校安人員及專案助理。人事協調往往牽涉學校法令、權利義務與人際信任。

---

## 一、校園人事溝通三大核心原則

1. **依法為基，情理為輔**：
   - 任何排課、兼課、監考、差假或績效評核要求，均先檢核是否有校內規章（如教師聘約、排課原則、考核辦法）為依據。
   - 溝通時避免以「長官命令」威壓，而應說明「制度目的、對學生的影響、大家共同分擔之必要性」。
2. **書面存證與程序透明**：
   - 重要調動、兼職、排課異動或陳情申訴，務必留下書面紀錄、會議簽名或公務電子郵件紀錄。
3. **同理與尊嚴維護**：
   - 面對教學不力、出缺勤異常或情緒困擾之同仁，應先以關懷面談為主，非必要不先啟動正式調查懲處程序。

---

## 二、常見溝通情境

- **排課與兼課協調**：特殊時段（如第一節、第八節、週五下午）協調、超鐘點負擔調度。
- **校務工作分工**：出任導師意願調查、兼任行政職務推薦與慰留、社團指導協調。
- **差勤與差假管理**：公差假審核原則、請假代理順序、事病假累積與成績考核之連動說明。
- **平時考核與親師衝突調解**：家長投訴處理回饋、同仁間協作衝突、評鑑與考核自陳輔導。
