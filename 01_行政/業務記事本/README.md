# 工作與教學業務記事本 (B01_記事本)

本目錄為個人專屬的「工作與教學業務紀錄中樞」，旨在協助高工資訊科老師／學校行政幹部隨時捕捉課堂隨筆、行政交辦、專案進度與會議重點，並透過 AI 進行結構化歸檔、週期性彙整與檢索。

---

## 快速目錄索引

| 目錄名稱 | 用途說明 | 適用情境 |
| :--- | :--- | :--- |
| **`_templates/`** | 標準紀錄範本庫 | 包含日誌、週報、課堂隨筆、交辦列管等 6 套標準 Markdown 範本 |
| **`01_日常日誌/`** | 每日/每週工作日誌 | 記錄每天工作排程、今日待辦與每日總結反思 |
| **`02_行政業務/`** | 行政與處室業務列管 | 記錄長官交辦事項、設備採購報修、公文追蹤列管 |
| **`03_教學業務/`** | 授課與實習工場隨筆 | 記錄各班教學進度、課堂學生反應、工場機台狀況備忘 |

| **`05_專案與活動進度/`** | 專案計畫與競賽培訓 | 記錄技藝競賽選手培訓、科展專案、競爭型計畫推動紀錄 |

```text
      ├──> 行政公文與重大法規案件 ──> 轉入 [A01_學校工作] 進行正式簽呈擬稿
      └──> 正式素養教案與分科教材 ──> 轉入 [A02_教學工作] 進行課程模組化開發
```

## 常用協作指令範例

您可以直接對 AI 下達自然語言指令，例如：

1. **隨手雜記轉為標準紀錄**：
   > 「幫我記錄今天資二甲上 Python 迴圈，有三位同學（座號 05, 12, 23）還是不太懂 while 條件設定，下次實習課要先花 15 分鐘幫他們做除錯練習，另外第 3 排那台桌機電源供應器有異音要報修。」
2. **生成今日工作日誌**：
   > 「請根據我今天記錄的事情，幫我產出今天的《工作日誌》並歸檔到 `01_日常日誌`。」
3. **每週行政與教學週報彙整**：
   > 「幫我統整這週在 `02_行政業務` 和 `03_教學業務` 的紀錄，產出本週業務摘要。」
4. **追蹤待辦事項**：
   > 「幫我清點目前所有未完成的待辦事項，按截止日列出。」
